# Quickstart: Demo-Gameloop testen

1. Headless-Check (keine Skriptfehler):
   ```powershell
   & "D:\Program Files\Game_Engine\Godot_v4.7.2-stable_win64.exe" --headless --path game-3-atmosphere --import
   & "D:\Program Files\Game_Engine\Godot_v4.7.2-stable_win64.exe" --headless --path game-3-atmosphere --quit-after 300
   ```
2. Im Editor F5: Menü erscheint → "Steuerung" → zurück → "Neues Spiel".
3. Intro durchklicken (Leertaste) → Zimmer, "Woche 1 · Montag 08:00". Wohnheim-Boden ohne Kacheln.
4. Tab → Handy: Stundenplan (Mo 10:00 Vorlesung Gebäude B), To-dos, Kontakte, Karte (Stationen beschriftet).
5. Raus, zu Gebäude B laufen, vor 11:30 Vorlesung spielen → Prompt "laut Stundenplan: Bonus ×1,3".
6. Gebäude LB: Lerngruppe (Memory) spielen. To-dos zeigen Fortschritt.
7. Gebäude A: Abgabe → "erst am Freitag".
8. Im Bett schlafen bis Freitag → Gebäude A → Abgabe: Intro nennt Schwierigkeit → spielen.
9. Wochenbilanz: Note, Ursachen, Klausurpunkte → "Hauptmenü" → Neues Spiel: Werte zurückgesetzt,
   Klausurpunkte bleiben.
10. Variante: Freitag nach 18:00 ohne Abgabe → Bilanz "nicht abgegeben".
