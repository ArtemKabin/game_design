# 0003: Title "Deceptive Wiring" and spaceship setting

* Date: kickoff meeting, October 2026 (recorded 2026-10-04)
* Status: accepted
* Participants: Person A, Person B

## Context
Eight title candidates were brainstormed. The setting had already been agreed earlier: the game concept resembles "Among Us" (spaceship, rooms, tasks), so that game serves as a reference for structure and look.

## Decision
Title: **Deceptive Wiring**. Setting: a spaceship, with "Among Us" as reference.

## Consequences
The title is itself part of the puzzle design: the wiring UI in Level 0 is a red herring that plays on the name. Rooms are spaceship areas (bridge, cargo bay, and so on). The tutorial level and the first real level were written out in full text and approved by both developers; four further level concepts were created with AI assistance and are backlog (see 0006).
