# Art sources (Aseprite)

Source files live here, exported sheets go to `../assets/`. Edit the `.aseprite`
files in Aseprite, then re-export (see below). Never edit the PNG sheets by hand.

## shaggy.aseprite — the player

Canvas 48 x 68, facing right. Ground line is y = 66. Frames:

| Tag  | Frames | Duration | Notes |
| :--- | :--- | :--- | :--- |
| idle | 1–4 | 150 ms | breathing bob (frames 2–3 one px down), raised arm shivers one px left/right (frames 2 and 4), sweat drops on 2 and 4 |
| run  | 5–8 | 90 ms  | legs: contact stride on 5 and 7, lifted knee on 6 and 8; body and arms two px up on 6 and 8, one px forward on all four |

Layers, bottom to top:

| Layer | Content | Exported as |
| :--- | :--- | :--- |
| `arm_back_red`  | red-lantern pose: LEFT arm hanging behind the body with the BLUE lantern | `shaggy_arm_back_red` |
| `arm_back_blue` | blue-lantern pose: LEFT arm raised sideways behind the body, BLUE lantern + glow at chest height | `shaggy_arm_back_blue` |
| `legs` | hips, legs, shoes (redrawn per run frame) | part of `shaggy_body` |
| `body` | head, hair, face, neck, shirt | part of `shaggy_body` |
| `arm_front_red`  | red-lantern pose: RIGHT arm raised in front with the RED lantern + glow | `shaggy_arm_front_red` |
| `arm_front_blue` | blue-lantern pose: RIGHT arm hanging at the hip with the RED lantern | `shaggy_arm_front_blue` |
| `fx` | sweat drops | part of `shaggy_body` |

Rule: the RED lantern is always in the RIGHT hand, the BLUE lantern always in
the LEFT hand. The world flip only changes which arm is raised.

In Godot the player is three stacked sprites: arm_back, body, arm_front. All
sheets have the same frame size, order and tags, so they play the same
animation and frame; the flip swaps the two arm textures.

Keep in mind when editing:

* The body and arm layers are the same drawing on every frame, only the cel
  position differs (bob/lean). If you redraw the head on frame 1, copy the cel
  to frames 2–8 (Aseprite: select cels, right click, "Link Cels" also works) and
  re-apply the offsets above, or ask the assistant to propagate.
* The legs layer is drawn fresh per run frame. Edit each of frames 5–8.
* Arm layers of the SAME pose share offsets with the body; the other pose's
  layers are hidden while you work but must get the same offsets.

## Re-export

Each sheet is "all frames, horizontal" with only its layers visible. Either use
File > Export Sprite Sheet in Aseprite with the layer filter, or ask the
assistant ("re-export shaggy"). The JSON next to each PNG carries frame
durations and the tags.

| `ghost_sphere.aseprite` | `../assets/hazards/ghost_sphere.png` | 4 frames of 28 x 36, tag `float` | the "sphere" hazard (`sphere.gd`): sheet ghost, bobs and blinks |
| `ghost_hunter.aseprite` | `../assets/hazards/ghost_hunter.png` | 4 frames of 28 x 36, tag `float` | the "star" hunter (`star.gd`): angry ghost, red eyes, shivers |

The tiles are drawn in neutral wood colours; the world mood (warm red /
grey-blue) comes from the full-screen filter in `world_filter.gd`, so one
texture serves both worlds. You can repaint them in Aseprite freely, keep the
sizes. The walkable top edge is the first 6 rows.
